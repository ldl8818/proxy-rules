# 自定义网站分流清单

仅保存公开域名规则，不保存节点、订阅令牌、密码或其他凭据。

| 文件 | 目标分组 |
| --- | --- |
| [claude.list](claude.list) | Claude专线 |
| [core.list](core.list) | 核心业务专线 |
| [default.list](default.list) | 海外默认（兜底） |

打开对应文件，点击编辑，按已有格式新增 `DOMAIN-SUFFIX,域名` 并提交到 main；根域名及子域名都会匹配。精确主机可用 `DOMAIN,完整主机名`。不填写 https:// 或网页路径。同一域名只放一份；换组时从原文件删除再加入目标文件。

这是既有业务规则之后的增补：已明确的核心、金融、直连等业务规则优先，新增网站在国内规则库和最终兜底之前处理。空文件合法；不要添加策略名、IP、关键字或其他规则类型。误改可从 GitHub 历史恢复。

首次接入完整配置后，日常无需重发节点或完整订阅：

- Mac Clash Verge Rev：规则 → 规则集合 → 更新全部；也可单独更新 owner-claude、owner-core、owner-default。正常运行时每5分钟检查一次。
- 小火箭：配置 → 当前完整配置 → 使用配置／编译配置；需要完整更新时选择更新配置后使用配置。首页节点刷新不代替规则更新。实际手机入口按版本验收。

下载成功并加载后，新连接使用新规则；网页可重新打开。GitHub 缓存、网络或下载失败会影响更新时间，不能承诺提交后零延迟。Mac 保留本地最后有效缓存；首次使用需要能下载清单。各业务组继续使用原手选出口。

客户端生成与发布由私有 proxy 项目维护，本仓库的三个 .list 文件是自定义增补的唯一来源。
