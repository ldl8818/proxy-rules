# 自定义网站分流清单

只编辑下面三份清单；它们公开可见，仅填写域名，不填写节点、订阅令牌或密码。

| 文件 | 目标分组 |
| --- | --- |
| [claude.list](claude.list) | Claude专线 |
| [core.list](core.list) | 核心业务专线 |
| [default.list](default.list) | 海外默认（兜底） |

填写 `DOMAIN-SUFFIX,cleanip.io` 或直接写 `cleanip.io`，覆盖根域名及子域名；精确主机写 `DOMAIN,主机名`。每组最多2000条、256 KiB，空清单合法。不要填写 URL、路径、端口或分组名称。

远程指定可覆盖内置分流。已登记业务入口会自动展开为整个业务族。例如把 `chatgpt.com` 放入 `claude.list`，会联动 OpenAI／Codex／ChatGPT／Sora 的已登记域名、关联接口和电脑进程／业务入口。Google／Gemini／Antigravity 也按现有 Google 业务族整体处理，包含 Google 登录及资源域名。普通网站按填写内容匹配。

共享服务按已登记的具体规则处理；同一主机被其他网站使用时也会受影响，浏览器和手机无法按发起网站准确区分。Claude Code 的独立住宅门禁不随域名覆盖放宽。目录以主项目的唯一业务源导出，`catalog.json`、编译器、工作流及 `generated/` 由维护程序同步，不手工维护第二份域名库。

一个业务族只放一个分组；换组时从原清单删除，再加入目标清单。跨组出现同族入口、相交的域名／后缀或共享关键词时，编译失败并保留上次有效产物。删除入口后恢复内置分流。

保存到 `main` 后，先在 **Actions → Compile owner rules** 确认最新一次运行成功，再更新客户端：

- Clash Verge Rev：规则 → 规则集合 → 更新全部，更新 `owner-*` 六份集合。订阅刷新不保证强制刷新集合；首次升级本功能需要更新一次原完整订阅。
- Shadowrocket：配置 → 当前完整配置 → 使用配置／编译配置；首次升级先更新配置。首页刷新主要更新节点，不能替代规则更新。手机实际菜单及加载效果需按版本实测。

Mac 的规则页搜索只匹配集合名称，不展开内部域名。新连接使用新规则，已有连接和 DNS 缓存可能仍沿用旧状态。工作流排队、GitHub Raw 缓存、网络及各份集合分别更新都会影响时效，不能保证保存瞬间或跨集合原子切换。失败继续使用有效缓存；首次无缓存时回到内置规则，覆盖暂不生效。各组手选出口保持，家庭版不接入。
